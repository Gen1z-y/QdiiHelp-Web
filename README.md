# 债基观察台 · QdiiHelp 网页版

独立于 Windows EXE / PostgreSQL 本地版的债基网页版。GitHub Pages 提供页面，计算在浏览器 Web Worker 中运行，个人数据保存在当前浏览器的 IndexedDB。偏好设置使用按项目路径命名的 localStorage。

- 公网页面：https://gen1z-y.github.io/QdiiHelp-Web/
- 代码仓库：https://github.com/Gen1z-y/QdiiHelp-Web
- 行情代理：https://qdiihelp-public-quotes.943982784qq.workers.dev

## 功能范围

- 仅添加可识别的人民币国内债基，保留持有/自选分组、搜索、排序、移除、手动刷新、正式净值、拟合预估、历史曲线及准确性统计。
- 保留基金对比、披露债券持仓同步、持仓变动和公告原文。同步时补充季度券种配置，作为新版非负岭回归的软约束；前五大持仓不放大为全部组合。同步后刷新基金数据。
- 删除全球指数页面、图片导出、浏览器备份导入/导出及相应业务接口。保留原国债、企债、转债模型作为回退；新版使用8个中债财富因子，覆盖分期限国债、政策金融债、信用债、中票和同业存单。
- 行情地址由 site/deploy-config.json 固定配置；页面没有修改入口，不再读取以前保存的 proxy-url。该地址是公开服务地址，不是密钥。维护者仍可修改配置重新部署；构建变量 QDII_PROXY_URL 可以覆盖。
- 同一浏览器配置文件共用数据；Web Locks 阻止第二个标签页同时写入。不同设备或浏览器配置文件各自保存，不提供注册登录、共享电脑上的账号隔离或跨设备同步。
- 数据说明面板可申请持久存储。清除网站数据、使用无痕浏览或更换浏览器可能失去记录；本版不提供备份恢复。关闭网页停止刷新。

## 债基识别与旧数据

目前按基金公开名称保守识别，不是完整的官方基金分类接口：名称包含“债”，同时排除混合、股票、货币、QDII、海外及外币份额等明显不适用类型。无法确认时拒绝添加，不能保证覆盖所有命名方式。模型只覆盖国内人民币债券，不将海外债基当作已支持。

升级时，已保存的非债基或类型待确认基金从活动列表移入本机 inactiveFunds，不再展示或刷新，原净值、记录及分组保留。已识别债基沿用原存储空间。可重新添加被误判或资料缺失但现已确认支持的债基；成功后解除停用。此次不读取或迁移本地版 PG 数据。

## 本地运行与验证

Node.js 22+，无 npm 运行依赖，不需要 PostgreSQL 或 npm install。

```powershell
npm test
npm run build
npm run preview
```

静态预览地址 http://127.0.0.1:8790/qdiihelp-web/ 。正式代理只允许 Pages 来源，普通本地预览无法获取真实行情。

```powershell
npm run verify:browser
```

这是仅监听127.0.0.1、拒绝8787的独立模拟验证服务。用浏览器打开 http://127.0.0.1:8790/_verify/ 查看集成检查；完成后可打开 /qdiihelp-web/ 操作模拟债基界面。它使用独立浏览器数据和人工行情，不访问PG或真实行情源。完成后Ctrl+C关闭。

## 发布

推送 main 后，GitHub Actions 运行单元测试、构建并发布 Pages。仓库 Settings → Pages 的 Source 为 GitHub Actions。

Cloudflare代理维护文件为 proxy/worker.mjs 和 proxy/wrangler.jsonc，使用 Wrangler 登录和部署；凭据不得进入源码仓库。代理限制来源、数据源/路径/参数、请求方法、响应大小和超时，使用公共缓存及每IP每位置约600次/分钟的近似限流；并非用户鉴权或严格全局配额。当前代理沿用原部署，本次精简不更改账号或收费套餐。

代理不保存个人业务状态，但公开基金/证券查询及访问元数据可能被服务商或上游记录。数据源可能超时或受地区、反爬限制；失败不能当成零涨跌。没有承诺全部市场及长期稳定性。详见 VERIFICATION.md。

估算仅供参考，以基金公司公布为准。许可证见 LICENSE。

## 持仓约束模型 bond-fit-v2

每只基金独立比较90日、160日及近期加权候选，采用季度券种占净值比作为非负岭回归软先验，保留超过100%的债券敞口。财富指数已含利息，不重复添加票息。报告仅在公布日之后使用，目标日或未来净值不参与训练。

候选须通过此前30日逐日选择门槛：MAE至少降低5%，最大误差不超过原模型1.1倍，最近10日MAE不超过1.05倍；否则保留原三指数模型并说明原因。中债目标日与前一交易日收盘数据未齐时等待，不提前封存旧模型。新旧封存及准确性统计独立，历史选择结果不保证未来效果。

升级后刷新页面，在基金持仓里同步一次补充季度配置，再刷新债基。旧封存值保持不变，新模型用于后续未封存日期。网页版需配套部署proxy/worker.mjs，旧代理不能读取新增来源；失败时会说明原因并保留原模型。
